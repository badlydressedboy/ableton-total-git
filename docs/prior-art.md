## Reader decisions

ALS is gzip XML with many `Value` attributes. Track names, clip slots, arrangement events, nested racks/chains, macro targets and routing live in different subtrees; a broad descendant search for a name or device can attribute a child to the wrong owner. Read direct names, retain parent-chain context, and scope IDs to their owners. Preserve source order, tolerate unfamiliar device tags, and support MasterTrack and MainTrack.

This milestone extracts a documented subset rather than promising a complete format specification. Unknown XML is ignored, but invalid gzip/XML and missing LiveSet/Tracks fail visibly. Macros and routing are best effort; opaque plugin state, automation and note-by-note differences remain future work. The original Set is always read-only. Derived JSON is the comparison contract, and Markdown is a musician/Codex view of that contract.
