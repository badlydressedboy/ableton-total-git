# First Windows release

Keep a Git history of your Ableton project library from a Max for Live device: review changed files, write a Commit Comment, and commit and push without leaving Live.

## Download and install

Download **max-for-live-win-x64.zip** below and extract the complete package into a permanent writable folder. Keep **Ableton Total Git.amxd**, its scripts and the `companion` folder together, then drag the device into Live. After upgrading, remove and re-add the device to load its new embedded patch.

Requires Windows x64, Ableton Live with Max for Live / Node for Max, Git and Git LFS. The .NET companion runtime is included. Configure your Git author and authentication before committing or uploading.

## Included

- One Git repository for all projects in your chosen library folder.
- Changed-file preview with slim scrollbars and automatic refresh while visible.
- A single Push button that commits first and uploads when a remote is configured.
- Optional GitHub remote setup, a Repo link and Git status access.
- Save Live Set, enabled when unsaved Set changes are detected.
- Readable Set reports, original ALS history and Git LFS for project-local media.
- MIT licence and the complete companion runtime.

The accompanying **max-for-live-win-x64.zip.sha256** file contains the package checksum.

## Early release and collaboration

This is an early release. ALS compatibility and native Live/Max UI behaviour are still being validated. The Save cursor workaround needs further hands-on testing; unsaved-change detection on Windows follows Live's English window-title marker. Restore earlier versions through your usual Git tools. See the [current limitations](https://github.com/badlydressedboy/ableton-total-git/blob/main/docs/limitations.md).

Windows is the only released platform for now. Mac build entries are commented out; the source is retained for contributors who can help validate it.

[Suggest a feature](https://github.com/badlydressedboy/ableton-total-git/issues/new?template=feature_request.md), report a reproducible bug, or collaborate on a pull request. Feature ideas, real-world testing and documentation contributions are welcome. See [CONTRIBUTING.md](https://github.com/badlydressedboy/ableton-total-git/blob/main/CONTRIBUTING.md).
